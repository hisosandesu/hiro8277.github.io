# コードレビュー

コミットされていない変更の包括的なセキュリティと品質レビュー：

1. 変更されたファイルを取得: git diff --name-only HEAD

2. 各変更ファイルについて、以下をチェック：

**セキュリティ問題（クリティカル）:**
- ハードコードされた資格情報、APIキー、トークン
- SQLインジェクション脆弱性
- XSS脆弱性  
- 入力検証の欠如
- 安全でない依存関係
- パストラバーサルリスク

**コード品質（高）:**
- 50行超の関数
- 800行超のファイル
- 4レベル超のネスト深度
- エラーハンドリングの欠如
- console.log文
- TODO/FIXMEコメント
- 公開APIのJSDoc欠如

**ベストプラクティス（中）:**
- ミューテーションパターン（イミュータブルを使用）
- コード/コメントでの絵文字使用
- 新しいコードのテスト欠如
- アクセシビリティの問題（a11y）

3. レポートを生成：
   - 重大度: クリティカル、高、中、低
   - ファイル場所と行番号
   - 問題の説明
   - 修正の提案

4. クリティカルまたは高の問題が見つかった場合はコミットをブロック

セキュリティ脆弱性のあるコードは決して承認しない！
