# リファクタリングクリーン

テスト検証付きでデッドコードを安全に特定し削除：

1. デッドコード分析ツールを実行：
   - knip: 未使用のエクスポートとファイルを発見
   - depcheck: 未使用の依存関係を発見
   - ts-prune: 未使用のTypeScriptエクスポートを発見

2. .reports/dead-code-analysis.md に包括的なレポートを生成

3. 発見を重大度で分類：
   - SAFE: テストファイル、未使用のユーティリティ
   - CAUTION: APIルート、コンポーネント
   - DANGER: 設定ファイル、メインエントリポイント

4. 安全な削除のみを提案

5. 各削除の前に：
   - 完全なテストスイートを実行
   - テストが通過することを確認
   - 変更を適用
   - テストを再実行
   - テストが失敗したらロールバック

6. クリーンアップされたアイテムの概要を表示

テストを先に実行せずにコードを削除しない！
