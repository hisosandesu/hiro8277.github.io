# 検証コマンド

現在のコードベース状態に対して包括的な検証を実行します。

## 手順

この正確な順序で検証を実行：

1. **ビルドチェック**
   - このプロジェクトのビルドコマンドを実行
   - 失敗した場合、エラーを報告して停止

2. **型チェック**
   - TypeScript/型チェッカーを実行
   - file:line付きですべてのエラーを報告

3. **Lintチェック**
   - Linterを実行
   - 警告とエラーを報告

4. **テストスイート**
   - すべてのテストを実行
   - 通過/失敗数を報告
   - カバレッジパーセンテージを報告

5. **console.log監査**
   - ソースファイルでconsole.logを検索
   - 場所を報告

6. **Gitステータス**
   - コミットされていない変更を表示
   - 最後のコミット以降に変更されたファイルを表示

## 出力

簡潔な検証レポートを生成：

```
検証: [PASS/FAIL]

ビルド:    [OK/FAIL]
型:        [OK/X errors]
Lint:      [OK/X issues]
テスト:    [X/Y passed, Z% coverage]
シークレット: [OK/X found]
ログ:      [OK/X console.logs]

PRの準備: [YES/NO]
```

クリティカルな問題がある場合、修正提案付きでリスト化。

## 引数

$ARGUMENTSは以下が可能：
- `quick` - ビルド + 型のみ
- `full` - すべてのチェック（デフォルト）
- `pre-commit` - コミットに関連するチェック
- `pre-pr` - フルチェックとセキュリティスキャン
